# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately using GitHub's "Report a vulnerability" button in the Security tab of this repository. You can also use this link: https://github.com/MeTheHan/discord-verify-bot/security/advisories/new

Include a clear description, steps to reproduce, and the impact you expect. We aim to acknowledge reports within 72 hours and to ship a fix for confirmed issues as quickly as possible.

## Scope

Issues affecting the public verification bot, its verification page, the OAuth flow, or the handling of bot tokens and secrets are in scope.
